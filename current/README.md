# MenuLink Menu

منيو عربي متجاوب مستوحى من أسلوب قوائم المقاهي الحديثة.

## التشغيل
افتح `index.html` مباشرة أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## التخصيص
- المنتجات والأسعار: `script.js`
- الألوان والخطوط: `styles.css`
- الاسم ومعلومات التواصل: `index.html`
